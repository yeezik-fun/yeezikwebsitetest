# yeezikwebsitetest

Sito di prova per il nuovo yeezik.com. HTML, CSS e JavaScript statici, senza librerie e senza preloader.

- `index.html`: Home
- `about.html`: About
- `music.html`: Music
- `events.html`: Events (booking e rider tecnico)
- `assets/style.css`: stile condiviso
- `assets/main.js`: animazione della scritta YEEZIK e pulsanti copia email

Per le foto: mettere i file in `assets/img/` e sostituire i riquadri `.frame` con un `<img>`.
